# 主题设置页 CSS 光标

## 范围

- 为主题自有设置面板的标题、说明、只读名称与数值直接声明 CSS 主题文字光标，覆盖深浅色及桌面、窄屏布局。
- 面板内的导入导出、头像裁剪、徽记编辑与页面内菜单保持原 DOM 归属，适用相同规则；不迁移弹窗、不包装文字、不改变任何尺寸或布局属性。
- 整个 `[data-prts-theme-settings]` 子树退出通用文字探测，不查询插入点、不测量文字片段，也不为当前文字添加局部内容或尺寸观察器。未知插件的通用兜底保持启用。
- 按钮、链接、折叠标题、控件标签、编辑区、工具栏、禁用态及显式拖动区域不套用普通文字规则，保留各自点击、输入和拖动语义。
- 面板和设置行容器保持默认光标；块级说明自身盒子内仍可能包含 I 形光标空白，不追求逐字轮廓。系统光标模式不启用新 CSS。
- 保留现有通用兜底及其性能优化；未修改版本号、依赖、DSH 支持范围和问答卡片。

## 验证设计

- 单元测试要求设置面板及嵌套弹窗在移动、滚动、尺寸变化和文字更新时，不调用插入点 API、不创建 Range 或文字观察器。
- 浏览器检查深浅色 × 1440／390px 的全部七个设置页签、页面内下拉菜单、导入导出弹窗、文字拖选和系统模式；比较每页文字与元素几何不变，并检查关闭设置后未知插件仍能进入兜底。
- 独立控件矩阵检查交互后代、控件标签、编辑框、禁用态、工具栏、徽记拖动与裁剪区域不会被普通文字光标覆盖。
- 真实宿主测试仅切换设置页签、打开只读菜单／导入导出窗口，不选择或导入文件；阻止配置、会话、命令及主题素材写入，并统计设置范围内的插入点与片段查询。
