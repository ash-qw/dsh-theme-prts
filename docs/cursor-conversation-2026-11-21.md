# 会话正文 CSS 光标统一试用

日期：2026-11-21。用户接受右侧预览的轻量光标方式后，要求先提交现有改动，再尝试将会话正文统一为 CSS 文本区域光标。

## 提交检查点与范围

- 试用前提交：`82ebd57`（`fix(ui): 适配问答档案卡与文件预览光标`），保留已验收的问答卡片及右侧预览版本。没有包含用户备份文件 `src/styles/refinement.css.orig`。
- 本轮将 AI 回复、推理正文、用户气泡、临时回显、待发送及正式插话改为 CSS 继承文字光标。优先使用原生文本源标记，并保留既有 Markdown、消息气泡结构的兼容入口。
- 初版未照搬预览的 `fit-content`，而是让整个正文继承 I 形。用户实测指出明显空白仍被覆盖，因此后续按本文末尾的范围收紧修正，不再沿用初版的整块继承。
- 原生按钮、链接、输入框、禁用态、拖拽、缩放边界、代码工具栏与显式文本交互排除标记保留各自光标。不是通过 CSS 推断所有元素的 `user-select` 计算值；未带排除标记的普通非选择性标签仍可能继承正文光标。
- JS 精确字符命中入口限定为首页标题，保留其既有交互；会话正文不再调用插入点 API、构造字符范围、测量字符矩形或写入文字命中标记。原有指针调度、缩放光标、手形动画和点击反馈仍在，不宣称鼠标移动完全没有 JS 工作。
- 右侧预览的范围收紧规则不变，问答卡片设计不变。试用改动暂不提交，也不推送或公开发布。

## 验证设计

- 单元测试对 AI／用户／旧结构／回显／插话执行移动、滚动、窗口变化与点击，禁止调用插入点 API 或创建字符范围；另行保留首页标题精确命中的回归用例。
- 浏览器覆盖经典与 Baker、深浅色，检查 CSS 在移动鼠标前即生效、正文留白、复制／链接／折叠等控件、输入与拖选、流式新增文字和系统模式。只切换光标模式，比较不同宽度和缩放下的文字矩形与元素盒子，要求布局一致。
- 长会话结构测试包含 1,200 个段落的持续移动、滚动、追加文字和空闲采样，核对字符定位、字符矩形测量与文字命中属性更新为 0。帧间隔阈值用于捕捉严重停顿，不是 60 FPS 或全场景性能保证。
- 原生组件测试在独立浏览器上下文挂载宿主 `MarkdownText` 与 `UserMessageBubble`，覆盖两种主题、两种会话样式、流式增长到结束、文字／空白／控件和布局比较；同时保留原生文件预览专项。不创建真实会话、发送模型请求或写入持久化用户设置。

## 验证结果

- `npm run check`：构建及 666 项单元测试通过，0 失败、0 跳过。最终 25 项浏览器回归通过，包含 5 项会话 CSS 光标专项、9 项既有光标回归和 11 项文件预览专项。
- 四种深浅色／会话样式组合在 360／680px 正文宽度与 80%／100%／125% 缩放下比较光标切换前后的文字矩形及元素盒子，样本布局一致；未移动鼠标时正文 CSS 即已生效。新增控件内部带 Markdown 标记或类似类名的回归，避免兼容选择器将控件标签误设为文字光标。
- 1,200 段落样本持续移动、滚动、追加文字及移出后空闲采样通过，插入点 API、字符矩形测量和文字命中标记更新均为 0；限定窗口内超过 20 帧、最大帧间隔低于 1 秒。该阈值只排查严重停顿，不证明 60 FPS 或所有用户会话的性能。
- 部署前候选客户端的两项原生深浅色专项通过，均涵盖经典与 Baker 原生正文和回显气泡、流式更新及结束、正文留白、链接和代码按钮，同时保留六种语言的原生文件预览检查。原生 Markdown 控件测试使用 HTTPS 链接；宿主会将纯锚点链接渲染成普通文字，不能把纯锚点样本当作可悬停链接来验收。
- 首次原生验证在页面加载阶段遇到宿主连接重置，日志记录两次 `fatal uncaught exception: Error: socket hang up`，自动重启后服务健康；当时安装的仍是检查点客户端，没有部署试用构建。重新获取认证状态后重测通过，没有修改宿主网络或异常处理代码，也不据此推断连接重置的底层原因。

## 实测反馈后的范围收紧

- 原因：初版只统一了 CSS 光标机制，没有应用右侧预览的范围收紧规则，Markdown 根容器的所有空白均继承文字光标，范围确实比预览宽。
- 修正：Markdown 根容器改为默认手形，仅段落、标题、列表项、定义项与代码行按内容设置 `fit-content` 和文字光标。引用、列表容器、代码块外框及空代码行保持默认光标；短段落右侧、段落间隙及空白占位区域不再整体显示 I 形。
- 不改宿主 DOM，不添加逐字测量；用户气泡外框不收窄。实际空格、换行段落部分末行空白、表格单元格和直接容纳纯文本的用户气泡内部仍可能显示 I 形，保留 CSS 区域方案的边界，不宣称字符级精确。
- 浏览器布局断言改为比较真实文字节点矩形以及气泡、引用、表格和代码块外框，而不是要求短段落盒子仍占满整行；同时验证短标题、短段落、引用文字及短代码行右侧为空白手形，保留流式与无字符测量回归。
- 验证：构建及 666 项单元测试通过；25 项光标与预览浏览器回归通过，扩充短标题／引用／代码行空白检查后另行重跑 5 项会话专项通过。候选构建及部署后的两项原生深浅色专项分别通过，安装后测试未注入候选客户端。
