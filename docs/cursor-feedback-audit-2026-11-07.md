# PRTS 原生光标定点点击反馈验证（2026-11-07）

## 实现与视觉修正

- 可交互控件保留完整按下、按住及松开帧；删除后代数量统计与原有 128 / 256 元素分档，不再为每次点击枚举后代。
- 非交互区域仅在显示手形光标时于点击坐标播放三圈弧形涟漪，不跟随鼠标、不逐帧替换光标图片。编辑、禁用、拖动、缩放与裁剪区域保留专用光标；2026-11-08 按反馈收紧范围，文本光标（含只读正文）不再触发涟漪，正文空白处的手形光标仍可触发，文本选择不变。
- 涟漪以圆形为基底，每圈具有四段不等长弧线、粗细变化、端点渐细与缺口，各圈旋转角度不同，不再是完整等宽圆。明确使用 `corner-shape: round`，避免宿主继承的 `superellipse(1.5)` 将其绘制成圆角方形。
- 相近波源使用共享 WebGL 图层叠加带符号的振幅，产生增强与抵消，不是独立透明度叠放。独立弧段 mask 与干涉纹理由同一组路径生成，避免两条路径的轮廓不一致；像素回读分别验证日 / 夜的增强、抵消和主题颜色。
- 同屏最多三处点击反馈，每处固定 4 个 DOM 元素、3 个 WAAPI 动画，约 650ms 内结束；相遇时最多额外 1 个共享 canvas。原生 dialog / popover 内的点击才将装饰节点提升到 manual popover，保证可见、不抢焦点或改变命中。

## 卡顿根因与优化

本地 knowlege 工作区“超长加载会话测试”含 10101 个正文后代、229974 个字符。此前版本在连续点击时出现约 0.5–1.2 秒的停顿。

- 性能诊断捕获到：干涉同步阶段对新插入涟漪调用 `getComputedStyle(...).color`，会触发约 500ms 的样式计算。移除读取后，点击处理显著缩短，但真实帧间隔仍有半秒以上停顿，说明仅移走同步读取并未解决后续绘制阶段的失效成本。
- 最终将反馈 DOM 与 CSS 放到稳定宿主的 Shadow DOM 中。连点、波源淘汰、动画结束和干涉画布更新均只修改内部树，不再反复变更正文所在的 body 子树；浏览器测试确认宿主 body 的 subtree MutationObserver 在整个反馈生命周期中没有新增记录。该隔离减少宿主选择器失效和观察器连带工作，不意味着宿主自身完全不再布局或计算样式。
- 移除反馈节点的计算颜色读取，按当前日 / 夜方案提交内建前景色；回归对照实际 CSS 颜色，覆盖动画中的日夜切换，不在每帧读取计算样式。
- WebGL 编译、纹理上传改为空闲预热，要求空闲回调剩余预算至少 12ms。预热本身仍有成本，预算检查不是硬实时保证；点击路径不初始化渲染器。未准备好时先保留独立弧段反馈，准备完成后才可接入干涉。
- 用缓存的 256×256 带符号纹理及 mipmap 替代原着色器逐像素重复的距离 / 指数计算；最多 3 个波源、9 个环、1 个局部画布，像素倍率上限 1.5。
- 相近连点复用已挂载画布，尺寸不变不重置 backing；淘汰旧波源与加入新波源合并同步，避免先缩小再扩大的重复刷新。

## 调度与降级边界

- 单处或相距较远的反馈仅用 WAAPI transform / opacity，没有逐帧 JS 定时器或 rAF。PRTS 模式开启且有空闲预算时可以预热一个 WebGL 上下文，即使随后没有发生重叠点击；不能再声称单次点击模式绝不创建上下文。
- 干涉需要一个短暂的 rAF 循环，每帧读取既有动画进度并上传小型 uniform 数组，没有后代扫描、光标跟随或每帧 DOM / cursor 写入。波源结束、取消或退回单处后立即停止。
- 不支持空闲回调、WebGL 不可用、图像解码 / 着色器失败或上下文丢失时退回独立弧段反馈，不伪称降级路径具有干涉。
- 关闭动画、减少动效、失焦、页面隐藏、拖动及取消均清理播放中的反馈；空闲预热按生命周期取消，关闭主题、切系统光标或销毁适配器时释放渲染资源与宿主。实验跟随模式仍停用。
