# P.R.T.S. 视觉保真重构设计规格

日期：2026-08-21  
状态：设计已确认，待书面规格复核  
目标：修复 `dsh-theme-prts` 在 DeepSeek Harness Web `0.1.0-rc.7` 实机中的结构与视觉偏差

## 1. 背景与问题定义

第一版插件已能安装、启用、关闭并通过自动化测试，但实机效果只是“原 Harness 页面上叠加 P.R.T.S. 顶栏与单个右栏”，没有实现已确认概念稿的界面架构。真实页面仍保留大面积原生白色工作区，Operation Sessions、Tactical Overview 与 Operator File 没有形成独立区域，阿米娅档案因固定高度和 `object-fit: cover` 被二次裁切，中央会话与 Composer 也没有完成主题化。

本次属于架构级保真重构，不是局部 CSS 修补。概念图 `docs/assets/prts-console-concept.png` 是布局、信息密度、色彩和明日方舟辨识度的视觉基准；实现仍使用 HTML、CSS、SVG 和同人重绘资源，不把整张概念图作为页面背景。

## 2. 新增确认要求

1. 插件自行新增、不会随 Harness 语言设置变化的重要功能名称和状态必须使用中文，英文仅作为 P.R.T.S. 世界观标识、缩写或次级辅助文案。Harness 原生且已接入国际化的文本继续跟随用户语言设置，皮肤不得强制改写。
2. 皮肤不得造成组件文字不可见、重叠、裁切、低对比、被伪元素覆盖或因字体加载失败而错位。
3. 中文化仅适用于插件自有的固定展示文本，不篡改 Harness 的国际化文本、数据、行为、快捷键、可访问名称或持久化语义。

## 3. 目标与非目标

### 目标

- 在真实 rc.7 页面上重建概念稿的五区桌面结构，而非增加浮动装饰层。
- 让 Rhodes Island 徽记、P.R.T.S.、RIIC、阿米娅档案、大号行动编号与警戒图形一眼可辨。
- 让会话、Goal/Plan、Agent、Tool 和结果拥有同等清晰的信息层级。
- 完成暗色、亮色、桌面、平板和手机回退。
- 保留 Harness 的会话、导航、输入、附件、模型、权限、工具、Agent 与设置功能。
- 用真实 NAS 页面截图、几何断言、文字可见性与交互测试验收。

### 非目标

- 不 fork 或替换 Harness 前端。
- 不修改 Docker 镜像内的 Harness 源文件。
- 不卸载、修改或自动启用其他已安装皮肤。
- 不复制游戏截图或从游戏安装包提取素材。
- 不在此次重构中支持 rc.7 以外、尚未实测的 Harness 版本。
- 不重做 Harness 数据层，也不伪造不存在的遥测数据。

## 4. 技术路线

采用“原生扩展点优先 + rc.7 专用 DOM 适配器”的混合方案。

1. 浏览器插件继续通过 `dsh.client` 加载。设置中新增独立的“P.R.T.S. 终端”导航项和配置面板，优先使用 Harness 原生设置页扩展点；不得继续注入 `settings.general.item` 或把完整主题配置放入“通用设置”。
2. 运行时首先探测可用的 layout、sidebar、conversation 和 task 扩展点；可用时直接挂接。
3. rc.7 没有公开插槽的区域由版本化 DOM adapter 识别和编排。所有 rc.7 选择器集中在单独模块，不散落到主题控制器和组件代码。
4. adapter 只包裹、标记或重新布局现有节点，不克隆输入框、不替换事件处理器、不重建会话数据。
5. 找不到关键宿主节点时停止挂载完整 shell，记录一次命名空间警告并保留原 Harness 可用；可选模块缺失时只隐藏对应模块。

不采用纯 CSS 猜测选择器，因为它已在真实 rc.7 上失效；也不完整重建 Harness 外壳，因为这会复制交互与状态、显著增加兼容风险。

## 5. 桌面信息架构

全局状态栏下方使用五区网格：

1. **主导航轨**：保留原导航动作，以图标、中文短标签和 RIIC 模块编号呈现。
2. **行动会话**：独立显示当前与近期 Session，提供新建、选择及原有会话动作。
3. **主行动区**：显示行动标题、会话流、Agent/Tool 事件与命令 Composer，占据最大弹性宽度。
4. **战术总览**：独立显示目标、计划、Agent、Tool、结果及上下文状态。
5. **干员档案**：独立显示阿米娅 R001 视觉、分类图标、属性、简介和条码，不与战术总览混装。

在 1440px 基准视口中，导航轨保持紧凑，会话列约占 16%–19%，主行动区至少占可用内容宽度的 42%，战术总览与干员档案分别拥有可读的独立列。若宽度不足，优先收起右侧模块，不能把主消息与代码压缩到不可读宽度。

顶栏恢复概念稿中的品牌与状态层级：Rhodes/P.R.T.S. 品牌模块、`DeepSeek Harness` 主标题、当前行动编号、Doctor、模型、权限、连接/同步状态、日期时间。拿不到真实值时显示明确的中文“未提供”，不展示从 URL 截断出的伪 Session 名称。

## 6. 核心组件

### 行动会话

会话列表直接使用 Harness 当前节点和动作。主标题显示“行动会话”，英文 `OPERATION SESSIONS` 作为小号辅助标识。激活会话使用黄色侧标、大号行动编号和状态文本，标题必须允许两行或安全省略，并保留完整 tooltip/可访问名称。

### 主行动区

会话正文继续使用适合长中文、代码和日志的正常文档流，不把每段文字强制塞入高度固定的装饰卡。用户、P.R.T.S.、Agent 与 Tool 通过身份条、色标、图标和角标区分。代码块保留复制、滚动和折行行为。

Composer 的中文主操作为“执行”，视觉上使用黄色 `执行 / EXECUTE` 按钮；实际提交、快捷键、附件、模型与权限控件仍由 Harness 原组件负责。

### 战术总览

模块标题使用“战术总览”，分区使用“行动目标”“执行计划”“协同干员”“战术工具”“任务产出”。展示真实数据；无数据时使用克制的中文空状态，不用虚构内容填满版面。各区可折叠，状态同时使用文字、图标和颜色表达。

### 干员档案

干员档案与战术总览拆为两个独立列。桌面图像区目标高度约 390–430px，使用概念稿已确认的阿米娅头像与上半身肖像构图，并以 `contain` 或等效方案完整显示该肖像；禁止 CSS 再次裁掉耳部、面部或图内姓名。档案图固定展示，不提供全身图或展开交互。档案补齐“代号、职业、分支、武器、身高、生日、履历”等中文字段、职业类图标与条码。装饰性同人数据应明确固定，不冒充 Harness 运行时状态。

图像关闭时保留档案结构和品牌辨识度，右栏空间回流给战术总览或主行动区。

### 独立主题设置

Harness 设置导航中新增独立的“P.R.T.S. 终端”栏，与“通用设置”等原生类别平级。该栏集中提供主题启用、明暗模式、档案显示、纹理强度、动态效果、信息密度、面板默认状态、重置和安全恢复说明。

如果 rc.7 提供设置页面或导航扩展点，则使用原生扩展点注册；如果只提供现有的通用设置 item slot，则不使用该 slot，改由 `rc7-adapter` 在设置导航中添加插件自有入口和隔离面板。插件面板不修改原生设置表单的状态、提交和路由语义，关闭插件或卸载后必须完整移除。

主题总开关关闭时，独立设置入口仍可访问，以便重新启用；`?prts-safe=1` 下不挂载主题视觉，但设置入口或卸载恢复路径必须保持可达。设置面板中的固定标签使用中文，Harness 提供的原生控件文本继续遵循其国际化机制。

## 7. 中文文案与国际化边界

下表仅规范插件自行渲染、不会随 Harness 语言切换的固定文案。这些关键功能标签以中文为主：

| Harness 概念 | 中文主标签 | 英文/世界观辅助标签 |
| --- | --- | --- |
| Session | 行动会话 | OPERATION SESSION |
| Goal | 行动目标 | OPERATION GOAL |
| Plan | 执行计划 | OPERATION PHASES |
| Agent | 协同干员 | OPERATOR / AGENT |
| Tool | 战术工具 | TACTICAL DEVICE |
| Deliverable/Output | 任务产出 | MISSION OUTPUT |
| Workspace | 基建工作区 | RIIC WORKSPACE |
| Model | 神经模块 | NEURAL MODULE |
| Permission | 权限等级 | CLEARANCE LEVEL |
| User | 博士 | DOCTOR |
| Assistant | P.R.T.S. 核心 | DSH CORE |
| Send | 执行 | EXECUTE |

品牌专名 `P.R.T.S.`、`RHODES ISLAND`、`RIIC` 与行动代码保留英文。

Harness 原生菜单、按钮、输入提示、设置项、状态和错误信息如果已经接入其国际化系统，必须原样保留并继续随语言设置变化。插件不得用 CSS `content`、DOM 文本替换、MutationObserver 或硬编码翻译覆盖这些文本，也不得为了中文化隐藏原标签。插件只为自有 shell、档案、战术总览和装饰模块提供固定中文文案；若引用原生控件，应保留其当前语言、可访问名称和完整语义。

## 8. 视觉系统与素材

- 暗色：炭黑、冷白、Rhodes 黄、运行青和警告红；主工作区必须真正进入暗色，不留原生白色岛块。
- 亮色：冷白、浅灰、黑色结构线，保留暗色导航锚点；不是简单反相。
- Rhodes 徽记、P.R.T.S. 模块、职业图标、警戒斜纹、条码、地图等高线与网点纹理作为强辨识锚点，但不得覆盖正文。
- 阿米娅素材使用用户已确认的概念稿头像与上半身档案肖像，固定展示且不提供展开交互；`contain` 仅用于防止 CSS 二次裁切，不得再替换为泛化全身角色。
- 中文正文使用可靠的系统中文无衬线回退；行动编号与遥测使用等宽/窄体回退。不得依赖网络字体。
- 动画维持 120–220ms，`prefers-reduced-motion` 下移除非必要扫描和过渡。

## 9. 文字安全与可访问性

文字可见性是阻断发布的硬门槛：

1. 所有主题规则限定在 `html[data-dsh-prts]`，并优先使用设计 token，不对未知组件应用全局 `color`、`font-size: 0`、`color: transparent`、`overflow: hidden` 或强制固定高度。
2. 原生按钮、输入、选择器、弹窗、Tooltip、Toast、代码块和 Markdown 必须获得明确的前景/背景 token；禁用状态仍需可读。
3. 装饰伪元素默认 `pointer-events: none`，位于文字下层，不得遮挡光标、选择、点击或焦点环。
4. 中文标题允许自然换行；遥测 ID 可安全省略并提供完整值；正文、代码与结果区允许纵向增长或局部滚动。
5. 字体加载失败、200% 缩放、系统加粗文本和中英文混排时，不得出现关键文字消失或相互覆盖。
6. 正文与控件达到 WCAG AA；焦点环清晰；仅靠颜色不能表达状态。
7. 自动化检查关键元素的非零尺寸、可见性、前景/背景对比、文字溢出和遮挡风险。截图差异之外，还必须通过 DOM 几何与交互断言。

## 10. 响应式与交互

- 桌面：完整五区布局，战术总览与干员档案为独立列。
- 平板：导航轨和主行动区常驻；行动会话为左抽屉，战术总览与干员档案组合为右抽屉但仍保持两个分区。
- 手机：默认只显示紧凑导航、主会话和 Composer；会话与战术信息默认关闭，以全宽覆盖层按需打开。
- 抽屉支持触发器、遮罩点击和 Escape 关闭；关闭后焦点回到触发器；打开时管理焦点和背景交互。
- Composer 在任何断点都不能被抽屉永久覆盖，页面也不能因右栏打开而失去返回路径。

## 11. 模块边界与生命周期

重构后的浏览器端拆分为：

1. `rc7-adapter`：探测真实 rc.7 DOM、标记语义区域、读取可公开状态并观察导航变化。
2. `layout-shell`：建立五区网格、挂载自有顶栏、抽屉与独立右栏容器。
3. `status-projection`：把 Session、模型、权限、Goal/Plan、Agent/Tool 等已存在状态投影为中文展示模型。
4. `operator-dossier`：管理档案结构、素材和开关，不依赖战术遥测。
5. `theme-controller`：应用 token、明暗模式、密度、纹理和生命周期清理。
6. `settings-page`：注册或适配独立的 P.R.T.S. 设置导航与面板，管理插件偏好但不介入通用设置。
7. `accessibility-guard`：处理焦点恢复、Escape、遮罩和关键文字可见性开发断言。

启用时先完成宿主探测，再一次性挂载；禁用、卸载或安全模式必须移除插件拥有的节点、属性、observer、监听器和样式，并把移动过的宿主节点恢复到原位置。

## 12. 错误与兼容策略

- `?prts-safe=1` 始终阻止所有视觉挂载，只保留插件可被卸载的能力。
- adapter 仅针对 `0.1.0-rc.7`；无法确认版本或关键结构时执行安全回退，不用宽泛选择器猜测。
- 挂载操作具备事务性：任一步失败则按逆序恢复 DOM。
- 插件不自动覆盖其他皮肤设置；验收时在 P.R.T.S. 单独启用条件下测试，并额外验证关闭后无残留。
- 不新增运行时网络请求、分析统计或额外轮询。

## 13. 测试与实机验收

### 结构与单元测试

- 用真实 rc.7 DOM 镜像替换仅含理想 `data-slot` 的简化 fixture。
- 覆盖 adapter 探测成功、可选区缺失、关键区缺失、导航变更和完整恢复。
- 覆盖插件自有中文投影、空状态、长标题、超长路径与未知状态。
- 覆盖 Harness 原生国际化文本在语言变化后不被插件覆盖或缓存为固定中文。
- 覆盖批准肖像的固定比例与哈希、图像开关和 Tactical/Operator 分栏。
- 覆盖独立设置入口、配置持久化、主题关闭后入口仍可达，以及“通用设置”中不存在 P.R.T.S. 配置项。

### Playwright

- 暗色与亮色：1440px 桌面、1024px 平板、390px 手机、200% 缩放。
- 验证五区桌面几何、双右栏、主区背景、顶栏状态、中文关键标签和黄色“执行”按钮。
- 验证长中文回复、代码、工具结果、Agent、Goal/Plan、弹窗、Tooltip、Toast、表单控件均可见且可操作。
- 验证手机默认折叠、遮罩/Escape 关闭、焦点恢复和 Composer 可达。
- 验证主题关闭、重新启用与安全模式无控制台错误、无残留节点。
- 验证设置导航存在独立“P.R.T.S. 终端”栏、其控件可操作，并确认“通用设置”未被插件注入。

### 真实 NAS 验收

最终包安装到现有 `deepseek-harness` 容器后，至少取得真实 rc.7 暗色和亮色桌面截图，并与概念稿并排检查。验收不能只检查 shell 数量或根属性，必须断言：

1. 主工作区不再保持原生白色或错误主题背景。
2. 桌面存在五个可辨识功能区，Tactical 与 Operator 为独立列。
3. 阿米娅使用概念稿批准的头像与上半身肖像，图像未被 CSS 二次裁切且没有展开交互。
4. 顶栏展示真实或明确缺省的 Session、模型、权限与 Doctor 状态。
5. 插件自有关键功能标签为中文；Harness 原生国际化文本仍跟随所选语言；正文和组件文字在暗/亮模式均清楚可见。
6. Harness 原有导航、会话选择、输入与发送可正常使用。
7. 设置中存在独立“P.R.T.S. 终端”栏，“通用设置”不包含插件配置，主题关闭后仍可从独立入口重新启用。
8. 容器保持 `healthy`，重启计数不增加，插件关闭和安全模式可恢复默认界面。

## 14. 发布边界

重构完成后提升插件补丁版本，构建新的本地 tarball，更新现有 Web profile 并重启服务。保留旧包或 Git 提交作为可恢复点；不删除用户 localStorage，不触碰其他皮肤。若实机验收中任一关键文字不可见、五区结构未建立、档案仍被裁切或核心交互失效，则不得宣称完成。
