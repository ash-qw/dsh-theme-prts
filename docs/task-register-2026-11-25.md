# 任务清单：圆角厚玻璃事务面板

## 实现范围

- 沿用宿主 `TodoPanel`：任务数据、计数、状态翻译、折叠、键盘操作与 180px 列表滚动仍由宿主管理。
- 10px 圆角、边缘高光和 5px 底部侧面组成厚玻璃面板，不使用切角、纸张投影或重复竖线。紧凑抬头和任务序号保留事务清单识别；抬头保留 `TASK REGISTER` 英文眉题，最窄容器隐藏眉题以腾出空间。
- 深色用石墨蓝底、浅色文字，浅色用淡冷灰底、深色文字。底板不透明度跟随 soft／standard／clear／off：深色分别为 90%／82%／78%／100%，浅色为 96%／90%／86%／100%；清透档保留足够遮底，兼顾小字阅读。
- 模糊只作用于底板背后的背景。正文仅保留向下 1px、模糊半径 1px 的单层淡影，深色透明度约 18%，浅色约 10%；编号和状态小字不加投影，文字及其父层不使用滤镜或整体透明度。
- 关闭玻璃、浏览器不支持背景滤镜或系统要求减少透明度时，底板退回不透明；关闭玻璃或系统要求减少透明度时同时取消文字投影。
- 完成项为轻微倾斜的文字印章，不使用棋子；进行中为蓝色菱形呼吸，待处理为空框。
- 菱形仅动画化透明度和变换。系统要求减少动态效果或主题设置为减动效时保持静态。
- 容器宽度不超过 560px 时，计数移到抬头第二行，任务正文换行；保留宿主输入区宽度约束。任务行禁止 flex 收缩，按换行所需高度排布，再由原生列表滚动，避免长文本越出本行。
- 不添加运行时任务扫描或任务数据写入。新增样式见 `src/styles/task-register.css`，由构建脚本内联到客户端。
- 抬头使用的原始任务印章图像已在中英文第三方声明中记录出处，仅作装饰。

## 验证方式与边界

本次在本地 DSH `0.2.2-rc.5` 上验证，不扩大包中声明的宿主支持范围。

- `npm run build`：通过。
- `node --test tests/package.test.mjs`：9 项通过。
- `tests/e2e/task-register-live.spec.mjs`：9 项功能／布局检查及 2 项深浅色材质检查通过；最终窄屏行高修正另行验证 390px 深浅色与 320px 四档材质。
- 已安装客户端模式：圆角厚玻璃版本 11 项通过。随后修正 320px 长文本行收缩问题，并补充每行正文必须位于行边界内的检查；最终修正版部署后的 4 项重点回归全部通过，覆盖深浅色 390px 行高与 320px 四档材质。候选补跑时有一项因服务连接中断而失败，服务恢复后该项补跑通过。
- 浏览器覆盖深浅色、经典／Baker、1440px／390px，以及英文状态和两种减动效来源；检查文字印章、菱形动画、折叠键盘操作、任务更新、空清单消失、滚动和横向溢出。
- 新增 320px 英文清单的深浅色材质检查：遍历四档透明度，确认玻璃关闭时不透明且无滤镜／文字投影，字面父层无滤镜与透明度，正文仅单层 1px 淡影，状态字不带投影。计入边缘反光和当前行底色后，在最不利的纯黑／纯白背景上，正文、次级正文与状态文字对比度均不低于 4.5:1。
- 浏览器用例将当前安装宿主的 `TodoPanel.tsx` 与样式快照从仓库外编译，在已认证的真实客户端中渲染。未将宿主源码复制进仓库；测试不创建会话、不修改持久化设置。
- 这是原生组件集成验证；未将其记为某个历史会话中的真实任务数据验证，也未运行完整测试套件。

复现浏览器检查需提供已认证的 Playwright storage state，以及仓库外的宿主 `TodoPanel.tsx`、`TodoPanel.module.css` 快照目录：

```sh
PRTS_RC022_STATE=/path/to/storage-state.json \
PRTS_TODO_NATIVE_DIR=/path/to/native-todo-snapshot \
npx playwright test tests/e2e/task-register-live.spec.mjs
```

加上 `PRTS_TASK_INSTALLED=1` 可直接验证已安装客户端中的样式，省略候选 CSS 注入。
