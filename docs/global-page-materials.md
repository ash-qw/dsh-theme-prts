# 非会话页面透明背景与默认模糊（issue #5）

## 处理范围

保持既有的透图设计，不以实色画布遮住壁纸。撤回此前未提交方案中的 split 实色画布、卡片 / 模块 / 分类 token 改写，以及关闭模糊时强制不透明的回退。

| 模式 | 非会话主面板 |
| --- | --- |
| 默认 / 对应图片未启用 | 沿用原有主题背景，不新增背景板 |
| 分区（split，有会话图片） | 主栏、页面基础背景透明；单独背景板默认模糊 8px |
| 完整（full，有完整图片） | 同样保留透明背景，默认模糊 8px |

自动化任务页、详情面板和说明区域原有的透明效果保留。背景板本身完全透明、不增加底色或遮罩、不接收点击；不在页面内容祖先或每张卡片上叠加模糊。关闭玻璃时仅停用新增模糊，不改成实色画布。系统请求减少透明度时也停用这层新增效果，但不额外改写页面透明度；浏览器不支持 backdrop-filter 时自然保留透明背景，不强制填色。

## 实现与兼容性

- 根据宿主 `data-global-panel` 识别非会话页；旧结构通过 `main` 插槽以及 `main.conversation` / `conversation` 的排除关系兜底。切回会话后自动退出，不增加运行时观察器或逐页扫描。
- 仅在启用壁纸的非会话主栏，将 `--dsw-alias-bg-base` 局部设为透明，让使用此 token 的页面、页头和任务详情继续透图；不透明化 body，也不将 body token 全局透明化。
- 不重设背景层、settings-card、模块、边框或 ghost-active token，不改变既有卡片材质；第三方自行定义的背景不强制覆盖。因此这不是对所有第三方黑色卡片的强制透明化修复。
- 单个 `operation::before` 承担背景模糊；使用局部 `isolation` 放在内容后方，不设置 transform 或 fixed containing block。固定定位、sticky 操作与 body portal 另做回归。
- 会话正文、输入框原生 5px 模糊、侧栏及侧脊规则不变；会话快捷操作继续隐藏。
- 不新增设置，不修改配置格式、版本号或 DSH 支持范围；本次不提高源样式和客户端体积预算。
