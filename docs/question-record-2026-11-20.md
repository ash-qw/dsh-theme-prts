# 已回答问答档案卡：本地适配记录

日期：2026-11-20。本轮根据确认的视觉方案实现并本地试用，不提交、推送或公开发布，主题版本与 DSH 支持范围保持不变。

## 设计与范围

- 将已回答的问答记录视为独立的交互档案，不视为用户发送的普通消息。经典与 Baker 会话共用同一张卡片，不挂用户或 AI 头像，不继承两类用户气泡的颜色、轮廓、透明度或模糊参数。
- 保留小型索引页签、窄装订边与穿孔、分组编号。以中性烟灰半透明材质替代概念稿中的大面积纸白、暖褐色与整条青色标题；浅色采用冷灰白。
- 卡片按现有全局深浅色、四档玻璃和减少透明度／增强对比度请求调整材质，不新增设置或配置字段。清透档保留透底，同时提高问题文字对比，针对纯黑、纯白衬底检查可读性。
- 保留宿主完整问题、选项文字、多选、手填换行、跳过提示、原文回退、时间与复制按钮。答案使用中性折向标记，不把跳过记录标为成功勾选。不增加折叠、编辑或重新选择行为。

## 实现

- 新增 `src/styles/question-record.css`，在共享材质与凭证菜单样式之后接入客户端构建。
- 仅通过宿主稳定的 `data-question-reply` 与 `data-reply-outcome` 标记进入适配，限定原生宽度容器、气泡与定义列表的内部结构，不根据问答文案猜测类型，不修改宿主消息角色。
- 全部为 CSS 适配，不新增 DOM、观察器、轮询、运行时依赖或动画。标题、页签与计数属于装饰，使用空替代文本与非命中伪元素；保留原生分组的无障碍名称。
- 使用定义列表的 CSS 计数器生成组编号，列表末尾伪元素计算总数后定位到标题区；数据更新时随原生列表更新。无结构化问题的原文回退不显示虚假的计数。
- 单层背景与模糊位于卡片根节点，原生内层气泡保持透明且不模糊。移除主题标记即恢复原生渲染，不需要清理 DOM。
- 客户端相对本轮开始构建增加 6,113 字节，在新增的有界 6 KiB 构建预算内；源样式另受 8 KiB 契约约束。未引入游戏图片或其他新媒体资产。
